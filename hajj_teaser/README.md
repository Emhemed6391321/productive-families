# فيديو تشويقي للحج (30 ثانية، بلا صوت)

## السيناريو
| الثانية | الصور | النص على الشاشة |
|---|---|---|
| 0–3 | لقطات واسعة (الحرم، الجموع) بزووم بطيء | ملايين القلوب… |
| 3–6 | وجوه الحجاج | وجهة واحدة |
| 6–12 | الطواف، الإحرام، عرفة بإيقاع سريع | لبّيك اللهم لبّيك |
| 12–18 | منى، مزدلفة، رمي الجمرات | رحلة عمر… في أيام معدودات |
| 18–24 | الدعاء، الدموع، اللحظات الإنسانية | دموع، دعاء، وسكينة لا توصف |
| 24–27 | أجمل لقطات الختام | هذا كان حج العام الماضي |
| 27–30 | بطاقة ختامية | الحج القادم… هل أنت مستعد؟ + اسم الصفحة |

الصوت: لا يوجد (الفيديو بلا مسار صوتي إطلاقًا). إن توفّر تسجيل تكبيرات الحج
يمكن دمجه بـ `ffmpeg -i teaser.mp4 -i takbeer.mp3 -shortest -c:v copy out.mp4`.

## الاستخدام
```
python3 build_teaser.py مجلد_الصور -o hajj_teaser.mp4 --page "اسم الصفحة"
```
- كل صورة 0.75 ثانية (أقل من ثانية)، 36 صورة + بطاقة ختامية 3 ثوانٍ = 30 ثانية بالضبط.
- إن كانت الصور أقل من 36 تُكرَّر بالتناوب.
- الأبعاد الافتراضية 1080×1920 (ريلز). للمربع: `--size 1080x1080`.
- التأثيرات: زووم/تحريك بطيء، وميض أبيض عند كل قطعة، تدريج لوني، فينيت، حبيبات سينمائية، عناوين عربية بظهور واختفاء.
- المتطلبات: ffmpeg وPillow (مع raqm لعرض العربية).
