# بطاقة «تعليمية شات»

بطاقة تنبيه تُرسل للطالب/ولي الأمر لتوجيهه إلى تفقّد نظام المراسلات «تعليمية شات» لوجود رسالة جديدة،
بنفس الهوية البصرية للمعهد المتوسط للعلوم الشرعية (المكعبات الزجاجية الكهرمانية، الشعار، الشريط السفلي ومعلومات التواصل).

- `export/` — الصور النهائية بمقاس 1638×2048 (نفس مقاس منشورات المعهد) بثلاث خلفيات: `dark`، `amber`، `light`.
- `card.html` — مصدر التصميم. للتعديل غيّر النص ثم أعد التصدير؛ اختيار الخلفية عبر `card.html?theme=amber`.
- `assets/` — الشعار والشريط السفلي مقتطعة من تصاميم المعهد الأصلية.
- `fonts/` — خط Alexandria (Google Fonts، رخصة OFL).
