# حزمة الهوية البصرية - تنسيقية حجاج طرابلس ب

| الملف | المحتوى |
|---|---|
| `Tripoli-B-Brand-Guide.pdf` | دليل الهوية (12 صفحة A4 أفقي): الشعارات، الاسم والتوليفات، الألوان، الخطوط، الزخارف، الأنماط، قواعد الاستخدام، نماذج التطبيق |
| `Tripoli-B-Brand-Elements.ai` | كل العناصر في لوحة واحدة، متجهة، النصوص محوّلة إلى منحنيات (يفتح في Illustrator) |
| `Tripoli-B-Palette.ase` | لوحة الألوان (Illustrator / Photoshop / InDesign) |
| `svg/` | الشعاران بكل الألوان (شفاف + على خلفية)، النجمة، الفاصل، الزخرفة، الإطار، الأنماط |
| `png/` | الشعاران بخلفية شفافة عرض 2000 بكسل |
| `fonts/` | IBM Plex Sans Arabic (400/500/600/700) |

إعادة البناء: `python3 build_kit.py` (يحتاج playwright وpotracer وpoppler).
الشعاران متجهان بالتتبع الآلي من الصور المرجعية، وليسا الملف الأصلي للمصمم.
